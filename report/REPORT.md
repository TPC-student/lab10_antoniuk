Тема: Команди CLI та BASH.
Мета: оволодіти практичними навичками налаштування протоколу TCP/IP, діагностики мережевих з’єднань за допомогою утиліт командного рядка (CLI) та автоматизації файлових операцій і аналізу логів у середовищі оболонки BASH.
Обладнання та програмне забезпечення: персональний комп’ютер із встановленою операційною системою Windows та середовищем виконання BASH (Git Bash / WSL / Linux), мережевий адаптер, підключений до локальної мережі.
ХІД ВИКОНАННЯ РОБОТИ
1–3. Перевірка встановлення мережевого адаптера та розташування його драйвера.
Після запуску персонального комп’ютера було відкрито «Диспетчер пристроїв» (Панель керування → Система → Диспетчер пристроїв або команда devmgmt.msc). У розділі «Мережеві адаптери» перевірено стан встановленого адаптера: біля пристрою відсутні жовті знаки оклику чи червоні хрестики, що свідчить про коректну роботу обладнання без апаратних конфліктів.
У вікні «Властивості» мережевого адаптера на вкладці «Драйвер» (кнопка «Відомості про драйвер») визначено розташування системних файлів драйвера: основний виконуваний модуль драйвера знаходиться у системному каталозі C:\Windows\System32\drivers\ (файли з розширенням .sys), а інформаційний файл конфігурації встановлення драйвера зберігається у каталозі C:\Windows\INF\ (файл з розширенням .inf).
4. Налаштування параметрів протоколу TCP/IP та розрахунок маски підмережі.
Для перегляду та налаштування параметрів мережевого підключення відкрито «Центр керування мережами та спільним доступом» → «Зміна параметрів адаптера» (або виконано команду ncpa.cpl), відкрито «Властивості» активного підключення та обрано компонент «Протокол Інтернету версії 4 (TCP/IPv4)».
Отримані мережеві параметри локальної мережі (приклад для лабораторної мережі класу C):
— IP-адреса вузла: 192.168.15.101;
— Маска підмережі: 255.255.255.0 (префікс /24, у двійковому вигляді: 11111111.11111111.11111111.00000000);
— Основний шлюз: 192.168.15.254;
— Переважний DNS-сервер: 8.8.8.8.
Розрахунок параметрів підмережі: оскільки маска 255.255.255.0 містить 24 одиничні біти в мережевій частині та 8 нульових бітів у хостовій частині, загальна кількість адрес у підмережі становить 2^8 = 256, а кількість доступних для призначення вузлам IP-адрес дорівнює 2^8 - 2 = 254 (діапазон від 192.168.15.1 до 192.168.15.254; адреса мережі — 192.168.15.0, широкомовна адреса — 192.168.15.255).

6. Тестування мережевого з’єднання за допомогою утиліти ping з різними ключами.
Утиліта ping використовує протокол ICMP (запити Echo Request та відповіді Echo Reply) для перевірки доступності віддаленого вузла 192.168.15.254 та вимірювання часу затримки пакетів. Було протестовано роботу команди з основними ключами:
1) ping -n 5 192.168.15.254 — відправка фіксованої кількості (5) ехо-запитів замість стандартних 4;
2) ping -l 1024 -n 3 192.168.15.254 — відправка 3 пакетів збільшеного розміру (1024 байти корисного навантаження);
3) ping -f -l 1472 192.168.15.254 — заборона фрагментації пакета (-f) для перевірки максимального розміру блоку передачі (MTU = 1500 байт з урахуванням 28 байт заголовків IP+ICMP);
4) ping -i 64 -w 1000 192.168.15.254 — встановлення часу життя пакета TTL = 64 та часу очікування відповіді 1000 мс;
5) ping -a 192.168.15.254 — зворотне перетворення IP-адреси в мережеве ім’я вузла;
6) ping -t 192.168.15.254 — безперервне надсилання запитів до примусової зупинки комбінацією клавіш Ctrl+C.

7. Визначення маршруту проходження пакетів за допомогою команди tracert.
Утиліта tracert дозволяє простежити всі проміжні маршрутизатори (вузли переприйому), через які проходить пакет до цільового хоста, шляхом поступового збільшення значення поля TTL (починаючи з 1) та аналізу відповідей ICMP Time Exceeded. Застосування ключа -d прискорює трасування, вимикаючи перетворення IP-адрес у доменні імена.

8. Перегляд мережевих підключень та портів за допомогою команди netstat.
Команда netstat відображає активні TCP-з’єднання, порти, які прослуховуються системою, статистику протоколів та таблицю маршрутизації. Для діагностики використано ключі -a (усі підключення та порти очікування), -n (відображення адрес і портів у числовому форматі) та -o (відображення ідентифікатора процесу PID).

ВІДПОВІДІ НА КОНТРОЛЬНІ ЗАПИТАННЯ
1. В які роз’єднувачі встановлюється адаптер?
Сучасні внутрішні мережеві адаптери встановлюються у слоти розширення PCI Express (PCIe x1, x4) на материнській платі; у застарілих системах використовувалися шини PCI або ISA. Зовнішні мережеві адаптери підключаються через порти USB (USB 2.0, USB 3.x, USB Type-C), а у ноутбуках раніше також застосовувалися роз’єми PCMCIA та ExpressCard.
2. Які типи адаптерів існують?
За способом підключення до середовища передачі даних розрізняють дротові (Ethernet для витої пари та оптоволоконні) і бездротові (Wi-Fi стандартів IEEE 802.11a/b/g/n/ac/ax/be). За конструктивним виконанням бувають інтегровані (вбудовані в материнську плату), внутрішні дискретні (плати розширення) та зовнішні (USB-адаптери).
3. Як визначити тип адаптера?
Тип адаптера можна визначити програмно через «Диспетчер пристроїв» (розділ «Мережеві адаптери»), за допомогою команд ipconfig /all або systeminfo у командному рядку Windows, команд lspci / lsusb в ОС Linux, а також візуально — за маркуванням на платі та типом зовнішнього роз’єму.
4. Як визначити, на якій швидкості може працювати адаптер?
Максимальну та поточну швидкість з’єднання можна переглянути у вікні «Стан» мережевого підключення в Windows, у властивостях адаптера на вкладці «Додатково» (параметр «Швидкість і дуплекс» / Speed & Duplex, наприклад 10/100/1000 Мбіт/с або 2.5/10 Гбіт/с), а в Linux — за допомогою команди ethtool <інтерфейс>.
5. Які роз’єднувачі може мати адаптер?
Для підключення мережевого кабелю адаптери оснащуються роз’ємами RJ-45 (для кабелю «вита пара»), оптичними портами SFP / SFP+ / LC / SC (для оптоволоконних ліній), коаксіальними роз’ємами BNC (у застарілих мережах) або коаксіальними конекторами RP-SMA для підключення зовнішніх Wi-Fi антен.
6. Як визначити, чи є фізичне з’єднання адаптера з концентратором?
Наявність фізичного зв’язку (лінку) визначається за світінням індикатора Link (зеленого або жовтого світлодіода) безпосередньо біля порту RJ-45 мережевої карти та на відповідному порту комутатора (концентратора), а також за відсутністю статусу «Мережевий кабель не підключено» в операційній системі.
7. Як встановити драйвер адаптера?
У більшості випадків сучасна операційна система встановлює драйвер автоматично за технологією Plug and Play після виявлення пристрою. Також драйвер можна встановити запуском інсталяційного пакета (.exe / .msi) від виробника обладнання або через «Диспетчер пристроїв» (контекстне меню пристрою → «Оновити драйвер»).
8. Як встановити драйвер адаптера, якщо він відсутній в Windows?
Необхідно дізнатися апаратний ідентифікатор пристрою (VEN та DEV) на вкладці «Відомості» → «ІД обладнання» у «Диспетчері пристроїв», завантажити відповідний драйвер з офіційного сайту виробника материнської плати чи чіпсета мережевої карти (на іншому ПК) і вказати шлях до розпакованої папки через майстер оновлення драйверів.
9. В якій папці розташовані інформаційні файли драйверів в Windows?
Інформаційні файли драйверів зберігаються у системній папці C:\Windows\INF, а самі пакети встановлених драйверів кешуються у сховищі C:\Windows\System32\DriverStore\FileRepository.
10. Яке розширення мають інформаційні файли драйверів?
Інформаційні файли встановлення драйверів мають розширення .inf (а скомпільовані предкешовані копії — .pnf).
11. Як відкрити вікно налаштування властивостей адаптера?
Відкрити «Панель керування» → «Мережа та Інтернет» → «Центр керування мережами та спільним доступом» → «Зміна параметрів адаптера» (або виконати команду ncpa.cpl у вікні «Виконати» Win+R), натиснути правою кнопкою миші на потрібному підключенні та обрати пункт «Властивості».
12. Для чого призначений на адаптері порт Wake-on-LAN?
Технологія та роз’єм Wake-on-LAN (WoL) призначені для дистанційного ввімкнення або пробудження комп’ютера зі сплячого режиму за допомогою спеціального мережевого пакета («Magic Packet»), надісланого локальною мережею на MAC-адресу адаптера. У сучасних PCIe-адаптерах живлення подається безпосередньо через шину PCIe без окремого кабелю.
13. Чи можна виконувати завантаження системи через мережевий адаптер?
Так, завантаження операційної системи по мережі можливе за допомогою технології PXE (Preboot Execution Environment), вбудованої в мікропрограму мережевого адаптера та BIOS/UEFI материнської плати.
14. Яких правил техніки безпеки слід дотримуватися при монтажі адаптера?
Перед встановленням адаптера необхідно повністю вимкнути комп’ютер, від’єднати кабель живлення від розетки та зняти статичний заряд (торкнутися заземленого металевого корпусу або використати антистатичний браслет). Забороняється торкатися контактних майданчиків і мікросхем плати руками та встановлювати плату під напругою.
15. Як налаштувати протокол TCP/IP?
У вікні «Властивості» мережевого підключення слід виділити пункт «Протокол Інтернету версії 4 (TCP/IPv4)», натиснути «Властивості» та обрати або автоматичне отримання IP-адреси та DNS через DHCP, або ручне введення статичної IP-адреси, маски підмережі, основного шлюзу та адрес DNS-серверів, після чого підтвердити зміни кнопкою «ОК».
16. Як встановити в Windows і Linux другу IP-адресу на адаптер?
У Windows: у властивостях протоколу TCP/IPv4 (при статичній конфігурації) натиснути кнопку «Додатково» (Advanced) і в розділі «IP-адреси» натиснути «Додати» (Add) або виконати команду netsh interface ip add address "Ethernet" 192.168.15.102 255.255.255.0. У Linux: використати утиліту iproute2 командою sudo ip addr add 192.168.15.102/24 dev eth0 або налаштувати додаткову адресу у конфігурації Netplan / NetworkManager.
17. Що таке DNS?
DNS (Domain Name System — система доменних імен) — це розподілена ієрархічна система, яка забезпечує перетворення зручних для людини символьних доменних імен вузлів (наприклад, google.com) у числові IP-адреси, необхідні для маршрутизації пакетів у мережі.
18. В якому випадку використовується автоматичне визначення IP-адрес?
Автоматичне отримання IP-адрес використовується в мережах, де розгорнуто сервер DHCP (Dynamic Host Configuration Protocol) — наприклад, у корпоративних мережах, домашніх роутерах та публічних точках доступу Wi-Fi. Це спрощує адміністрування великої кількості клієнтів і запобігає конфліктам однакових IP-адрес.
19. Для чого використовується команда ping?
Команда ping призначена для перевірки наявності мережевого зв’язку на рівні протоколу IP/ICMP між локальним комп’ютером та іншим мережевим вузлом, оцінки часу проходження пакетів (затримки) та визначення відсотка втрачених пакетів.
20. Як задати, щоб команда ping виконувалась нескінченну кількість разів?
В операційній системі Windows для цього використовується ключ -t (наприклад, ping -t 192.168.15.254). В операційній системі Linux нескінченна відправка пакетів увімкнена за замовчуванням до натискання комбінації Ctrl+C.
21. Що таке TTL пакетів?
TTL (Time to Live — час життя пакета) — це 8-бітне поле в заголовку IP-пакета, яке обмежує максимальну кількість проміжних маршрутизаторів (стрибків), через які може пройти пакет. Кожен маршрутизатор зменшує значення TTL на 1; коли воно досягає 0, пакет відкидається, що запобігає нескінченному зацикленню пакетів у мережі.
22. Як включити безперервну відправку запитів в ping?
У Windows безперервна відправка ехо-запитів вмикається параметром -t перед або після адреси вузла (ping -t <адреса>). Зупинка виконується натисканням Ctrl+C (а перегляд проміжної статистики без зупинки — Ctrl+Break).
23. Для чого використовується команда tracert?
Команда tracert (в Linux — traceroute) використовується для визначення повного маршруту проходження пакетів мережею із зазначенням усіх проміжних вузлів (маршрутизаторів) та часу затримки на кожному етапі, що дозволяє локалізувати ділянку обриву зв’язку або високих затримок.
24. Як встановити час очікування?
Утилітах ping та tracert час очікування відповіді (тайм-аут) у мілісекундах задається за допомогою ключа -w <час_у_мс> (наприклад, ping -w 2000 192.168.15.254 або tracert -w 1500 8.8.8.8).
25. Що таке bash?
BASH (Bourne-Again SHell) — це популярна командна оболонка та мова сценаріїв (скриптів) для UNIX-подібних операційних систем (Linux, macOS) та середовищ сумісності у Windows (Git Bash, WSL), яка забезпечує інтерактивне керування системою та автоматизацію виконання команд.
26. Яка стрічка на початку файлу повинна бути, щоби вказати на bash?
Першим рядком скрипта повинен бути так званий шебанг (shebang): #!/bin/bash (або більш універсальний варіант #!/usr/bin/env bash), який вказує ядру операційної системи шлях до інтерпретатора команд.
27. Що таке sed?
sed (Stream EDitor — потоковий текстовий редактор) — це утиліта командного рядка в UNIX/Linux, призначена для автоматизованого перетворення, фільтрації, пошуку та заміни тексту у файлах або вхідному потоці даних за допомогою регулярних виразів без відкриття файлу в інтерактивному редакторі.
